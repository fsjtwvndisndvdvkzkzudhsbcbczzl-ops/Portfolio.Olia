# 在线知识服务中的多智能体角色组合研究

## 基本信息

- 题目：《在线知识服务中多智能体角色组合对用户体验的影响——角色清晰度的中介作用》
- 项目类型：人智交互 / 多智能体 / 在线知识服务 / 用户实验 / 脑电评测 / 网页原型
- 当前状态：已有 13 页中文修改稿；正文未见作者署名、刊物或投稿状态

## 一句话定义

通过教师与同伴、教练、导师三种多智能体组合，比较角色分工如何影响用户对系统的理解、信任、满意度、社会临场感与认知投入。

## 研究问题与模型

研究把“角色组合”作为系统设计变量，把“角色清晰度”作为解释机制，考察三类知识服务体验：

- 社会临场感：用户是否感到自己在与一个可感知的社会对象互动。
- 感知信任：用户是否认为智能体具备能力并真诚提供帮助。
- 学习满意度：双智能体协作是否达到预期并提供充分支持。

同时使用 EEG 专注度与放松度观察认知投入状态，避免只依赖主观问卷。

## 角色组合设计

每组都包含教师智能体，并与第二个角色组合：

- 教师 + 同伴：强调经验交流、平等互动和情境支持。
- 教师 + 教练：强调过程指导、问题拆解和策略建议。
- 教师 + 导师：强调知识判断、结果评价和解释反馈。

角色设计同时使用形象线索与语言线索。正式实验前以 10 名非实验参与者完成角色识别预测试，所有参与者均能正确识别角色类型。

## 实验平台与流程

- 使用 HTML 与 CSS 搭建实验网页，包含用户信息、知识学习、任务测试、智能体反馈和体验评价模块。
- 学习主题为行为经济学与认知心理学中的“锚定效应”。
- 参与者观看教师智能体知识讲解视频后完成 10 道练习题，系统根据答案呈现对应角色的反馈。
- 全流程约 30 分钟；系统记录答题结果、作答时间、反馈阅读时间和页面交互，并同步采集脑电数据。
- 当前资料证明网页用于研究实验，不表述为面向真实用户上线的知识服务产品。

## 样本与方法

- 采用单因素三水平组间实验设计。
- 共招募 54 人，每组随机分配 18 人；剔除 9 份未通过注意力检测的数据后，获得 45 份有效样本。
- 有效样本年龄 18 至 25 岁；男性 19 人、女性 26 人。
- 使用 7 点 Likert 量表测量角色清晰度、社会临场感、感知信任和学习满意度。
- 使用单因素方差分析、Tukey HSD 和 10,000 次 Bootstrap 检验组间差异与中介效应。

## 主要结论

- 教师 + 教练组合在角色清晰度、社会临场感、感知信任和学习满意度等主观指标上整体表现最好。
- 教师 + 导师组合的 EEG 专注度最高，显著高于教师 + 同伴组；不同组合对 EEG 放松度的影响不显著。
- 角色清晰度显著中介角色组合对感知信任和学习满意度的影响。
- 角色清晰度对社会临场感的中介效应不显著，说明社会临场感可能更多来自语言温度、回应方式等情感线索。
- 对多 Agent 产品的直接启示是：分工本身还不够，系统需要用角色名称、视觉标识、职责说明和任务转接提示，使用户知道当前由谁提供什么帮助。
